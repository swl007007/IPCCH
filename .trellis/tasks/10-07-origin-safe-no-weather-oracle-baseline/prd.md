## Goal and evidence

Measure the incremental predictive value of assumed perfect weather forecasts and a fixed six-feature representation package while preserving the latest global baseline. Present the oracle-free reference first, then paired global and Southern Africa comparisons.

The existing `origin_safe_climate_idp_v1` already contains no weather oracle: all 12 run schemas and 192 saved booster feature lists were inspected. The reference `climate_safe_history_idp` includes shared-folder monthly climate, completed growing-season climate, five safe IPC-history features, two national IDP features and its other existing inputs. This is the original reference **configuration**, not an experiment falsely claimed to have run first. Inspection evidence and code anchors are retained in [research.md](research.md) and [integration-surfaces.md](research/integration-surfaces.md).

## Requirements

- **R1 — Preserve and verify the reference.** Reuse saved H0/H3/H6/H12 reference models and predictions only after input/artifact hashes, environment, feature order, fitting keys/weights/targets and model replay pass. Appended-arm inputs must reproduce every parent feature value, missingness mask, row and label exactly. Preserve old artifacts and original training fingerprints; discrepancies stop reuse rather than trigger an automatic baseline refit.
- **R2 — Weather-only availability hypothesis.** For target T, horizon H and origin O=T−H, add shared monthly `prcp_anom_month_ensmean` and `tmean_anom_month_ensmean` at O+1 through O+min(H,6). Treat realized values as 100%-accurate forecasts hypothetically available at O; record actual observation months separately. Only these weather terms and their declared transformations receive this exception. Historical climate, GS, IPC, IDP and fitting labels retain existing timing rules. H12 receives only the first six post-origin months; H0 receives none.
- **R3 — Three fixed configurations.** Compare reference, reference+raw oracle, and reference+raw oracle+B6. B6 adds, per weather variable, complete-window future mean F, equal-weight past/future mean B=(R+F)/2, and Q=F×1[latest safe IPC history1≥3]. F requires all future months finite; B also requires all past months and existing R finite; Q requires F and safe history1. Missing F never becomes zero under a zero gate. Dependencies and variables have independent missingness. No filling, row drops, extra missingness predictors or age thresholds. Exact formulas and names are in [design.md](design.md).
- **R4 — Fixed fitting and cohort.** Retain strict annual blocks for 2022–2025, cutoff Jan(Y)−max(H,1), weight origin Jan(Y)−H, half-life24, seed42, threshold0.2, n_jobs16 and fixed four-regressor configs. Each row retains its own origin. Keep all 28,205 evaluation keys, normalized share targets and reported overall-phase truth. Train only the two new arms at H3/H6/H12: six runs, 24 annual batches, 96 new regressors. H0 is one shared reference, without artificial oracle contrasts.
- **R5 — Comparable reports.** Report eight established metrics annually and pooled, using unrounded predictions, for all three arms and deltas raw−reference, B6−reference and B6−raw. Global primary results are point estimates. Label the last delta as the whole manual-package increment, not an isolated IPC interaction or causal effect. Record fitting/evaluation F/B/Q coverage by horizon, year and variable, source dates and history staleness as diagnostics only.
- **R6 — Southern Africa postprocessing only.** Extract existing GLOBAL-model predictions by `area_id` using `data/reference/area_id_country_region_mapping.csv`, `region=3`. Do not replace membership with SADC, UN M49 or a country whitelist. Baseline inspection found 3,234 keys, 1,021 areas, ten countries and annual counts 703/514/594/1423. Preserve paired keys across arms/horizons; reject duplicates, missing region membership, missing selected-country IDs or changed frozen inputs. Country IDs define bootstrap strata only. No pipeline rerun, global refit or regional/local model training for this addendum.
- **R7 — Regional bootstrap and conditional intervals.** Only country-stratified whole-area paired bootstrap: sample each country's observed N_c areas N_c times with replacement, carrying all rows for the selected period and sharing draws across comparisons. Preserve observation-row weighting. Report regional point metrics and paired-difference 95% intervals for annual and pooled periods, using 2,000 draws and PCG64(seed42). User selected conditional intervals from valid paired draws only, with at least 1,000 valid draws required; otherwise retain any defined point difference and mark its CI unavailable. Explicitly disclose conditional interpretation and invalid count/fraction, without zero substitution or replacement draws. Keep undefined statuses explicit and save reproducible draws. ## Decisions, exclusions and limitations

B6 was converged through three rounds with the existing Herdr Claude Fable5.1 xhigh pane `wP:p3`, session `693b5360-2bad-47d8-975a-e871d5930058`, then accepted for planning by the user. [feature-proposals.md](feature-proposals.md) preserves formulas, rejected candidates and transcript references. The stopped separate CLI attempt is not peer evidence. The latest user choices retain seed42 and country-stratified whole-area bootstrap. The requested grill-with-docs pass resolved G1 as conditional intervals and G2 as at least 1,000 valid paired draws; [final-alignment.md](research/final-alignment.md) records code evidence and boundary cases. No scientific design choice remains open. Final execution approval was subsequently granted: “批准，交给herdr pane另一个空闲的claude进入执行。”

Exclude A4/26-column alternatives, extra seeds, tuning, evaluation-driven feature selection, manual GS/IDP/conflict/price/static interactions, dry-hot products, endpoint trend bags and monthly refits. Region3 membership supersedes the earlier SADC candidate; see [regional evidence](research/southern-africa-scope.md) for mapping hash, country composition and prior alternatives.

The perfect-forecast assumption is not historical forecast-vintage evidence or a theoretical weather-value upper bound. Source revision, standardization and actual publication-vintage limitations of the baseline remain disclosed. Safe history1 may be stale; B is not a crop-season exposure measure. The regional bootstrap conditions on fitted models and observed countries/years, and does not capture common shocks across different areas in one country, model/seed uncertainty, new-country or future-year generalization. Gains may be zero or negative; neither outcome changes the frozen comparison.
